# ダンス練習アプリ（フェーズ0 / MVP）

ダンス動画をアップロードすると、一定間隔で区切り、区間ごとに「どう踊るか」の解説を日本語で生成する Web アプリです。

## できること

- 動画（mp4 など）をドラッグ＆ドロップでアップロード
- 一定間隔（初期値 2 秒、UI で変更可）で区切る
- 各区間の代表フレーム（開始・中間・終了の3枚）をサムネイル表示
- 各区間の3枚を Claude API に送って、動きの解説（日本語）を生成
- 区間のサムネイルをクリックすると、その区間だけをループ再生
- 再生速度の切り替え（0.25x / 0.5x / 1x）と左右反転（鏡像）表示

状態は React の `useState` だけで持っています。DB はありません。ページをリロードすると消えます。

## セットアップ

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. API キーの設定

1. https://console.anthropic.com/settings/keys で API キーを発行します（`sk-ant-` で始まる文字列）。
2. プロジェクト直下に `.env.local` というファイルを作ります。`.env.local.example` をコピーするのが早いです。

   ```bash
   cp .env.local.example .env.local
   ```

3. `.env.local` を開いて、発行したキーを貼り付けます。

   ```
   ANTHROPIC_API_KEY=sk-ant-ここに実際のキー
   ```

`.env.local` は `.gitignore` に入っているので、コミットされません。キーはサーバー側（Route Handler）でだけ読まれ、ブラウザには渡りません。

> キーを設定せずに解説を生成しようとすると、画面に「ANTHROPIC_API_KEY が設定されていません」と表示されます。設定後は **dev サーバーの再起動が必要** です。

### 3. 起動

```bash
npm run dev
```

http://localhost:3000 を開きます。

## 使い方

1. 10 秒程度の mp4 をドラッグ＆ドロップします。
2. 自動的に 2 秒ごとに区切られ、各区間のサムネイル3枚が表示されます。
3. 区切り間隔を変えたいときは「区切り間隔（秒）」を編集して「この間隔で区切り直す」を押します。
4. 「全区間の解説を生成」を押すと、先頭の区間から順に解説が出ます。1 区間だけ試したいときは、その区間の「この区間の解説を生成」を押してください。
5. サムネイルをクリックすると、その区間だけがループ再生されます。速度と左右反転は動画の下のボタンで切り替えます。

## 技術構成

| | |
|---|---|
| フレームワーク | Next.js 15（App Router）+ TypeScript |
| スタイル | Tailwind CSS v4 |
| フレーム抽出 | ブラウザ側で `<video>` の `currentTime` をシークし、`canvas.drawImage()` で JPEG 化（ffmpeg 不使用） |
| 解説生成 | Anthropic API（`claude-sonnet-4-6`）を Next.js の Route Handler 経由で呼び出し。画像は base64 の `image` ブロックで送信 |
| 状態管理 | React の `useState` のみ |

### ファイル構成

```
app/
  page.tsx              画面全体の状態と組み立て
  layout.tsx
  globals.css
  api/analyze/route.ts  Claude API を呼ぶ Route Handler（APIキーはここでだけ使う）
components/
  Dropzone.tsx          ドラッグ＆ドロップ
  VideoPanel.tsx        動画プレイヤー・区間ループ・速度・鏡像
  SegmentCard.tsx       区間1つ分（サムネイル + 解説）
lib/
  types.ts              Segment 型と区間の分割ロジック
  frames.ts             canvas によるフレーム抽出
```

### 解説生成のプロンプト方針

各区間について、以下の見出しで日本語の解説を返させています。

- 体の向き（正面 / 斜め / 背中 など）
- 足のステップ（左右どちらに体重、どこに踏み出すか）
- 腕・手の動き
- 頭・目線
- 一言のコツ

振り付けの正式名称は無理に当てさせず、見たままを言語化させています。画像から判断できない項目は「判別しづらい」と書くよう指示しています。

## 補足・制限

- フレーム抽出はブラウザのデコーダに依存します。ブラウザが再生できない形式（一部のコーデック）は読み込めません。
- サムネイルは横幅 480px・JPEG 品質 0.72 に縮小してから送信しています。
- 解説の生成は先頭の区間から順番（逐次）です。並列化・キャッシュ・書き出しはフェーズ3の予定です。

## 今後の予定

- フェーズ1: 音楽のビートに合わせた8カウント分割（BPM 検出 + タップテンポ + 開始オフセット調整）
- フェーズ2: MediaPipe の姿勢推定で骨格データを併用し、解説精度を上げる
- フェーズ3: 30秒〜1分の長尺対応（並列生成・逐次表示・キャッシュ・テキスト/PDF 書き出し）
